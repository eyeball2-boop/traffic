신호등 와이파이 설정 (컴퓨터 + USB)

장소가 바뀌었을 때 한 번만 하면 됩니다. 설정이 끝나면 USB를 빼고 전원만 연결해도 원격제어됩니다.

1
보드를 USB로 연결
2
와이파이 이름과 비밀번호 입력

⚠ ESP32는 2.4GHz 와이파이만 연결됩니다. 학교 와이파이가 5GHz라면 휴대폰 핫스팟을 켜고 그 이름과 비밀번호를 입력하세요.

3
연결 확인
USB로 보드를 연결하면 현재 상태가 표시됩니다.
설정 완료! 이제 USB를 빼고 충전기나 보조배터리로 전원만 연결하세요.
휴대폰에서는 아래 주소로 접속하면 이 신호등을 바로 제어할 수 있습니다.
지금은 파일로 열려 있어서 휴대폰에서 이 주소를 열 수 없습니다. GitHub Pages에 올린 주소 뒤에 를 붙여서 사용하세요.
설정 · 통신 기록

USB로 연결하면 장치 ID가 자동으로 입력됩니다. 휴대폰에서는 컴퓨터 화면에 표시된 ID를 입력하거나, 장치 ID가 붙은 주소로 접속하세요.

컴퓨터 없이 와이파이 바꾸기 (휴대폰)
  1. 신호등 보드에 전원을 연결합니다. 저장된 와이파이에 연결하지 못하면 약 20초 뒤 설정용 와이파이가 켜집니다.
  2. 휴대폰 와이파이 목록에서 TrafficLight-로 시작하는 와이파이를 고르고 비밀번호 12345678을 입력합니다.
  3. 설정 화면이 자동으로 뜨지 않으면 브라우저에서 http://192.168.4.1로 접속합니다.
  4. 새 와이파이 이름과 비밀번호를 입력하고 저장합니다. 화면에 나온 장치 ID를 이 웹앱의 설정에 입력하세요.
아두이노 IDE 코드 (traffic_light_remote.ino)

ESP32 Dev Module로 업로드하세요. 라이브러리 관리에서 PubSubClient(Nick O'Leary)를 먼저 설치해야 합니다. 와이파이 정보는 코드에 넣지 않습니다.
