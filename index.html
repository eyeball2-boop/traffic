Firebase 데이터베이스 연결

  1. console.firebase.google.com에서 프로젝트를 만듭니다.
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 (위치 아무거나, 테스트 모드로 시작)
  3. 규칙 탭에 아래 내용을 붙여넣고 게시합니다.
    {"rules":{"traffic":{".read":true,".write":true}}}
  4. 데이터 탭 맨 위의 주소(https://…firebasedatabase.app 또는 https://…firebaseio.com)를 복사해 아래에 붙여넣습니다.
