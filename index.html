이 컴퓨터에 신호등 연결 (USB)

신호등 보드가 USB로 꽂혀 있는 컴퓨터에서 이 버튼을 누르세요. 이 컴퓨터가 휴대폰의 명령을 보드로 전달합니다. 보드의 와이파이 설정은 필요 없습니다.

✅ 중계 중입니다. 이 창을 닫거나 최소화하지 마세요. 이제 휴대폰에서 같은 주소로 접속해 ON/OFF를 누르면 됩니다.

설정 · 통신 기록

공개 중계 서버를 사용하므로 장치 ID를 아는 사람은 누구나 제어할 수 있습니다. 여러 모둠이 함께 쓸 때는 모둠마다 다른 ID를 정하고, 그 모둠의 컴퓨터와 휴대폰에 같은 ID를 입력하세요.

아두이노 IDE 코드 (traffic_light.ino)

ESP32 Dev Module로 업로드합니다. 와이파이 정보와 추가 라이브러리는 필요 없습니다.
